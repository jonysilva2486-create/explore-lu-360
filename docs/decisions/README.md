# Explore Luxembourg 360 — Architecture Decisions

This directory records important technical and product decisions that affect the architecture of Explore Luxembourg 360.

## Decision policy

Architectural decisions should not be made silently.

For each significant decision we record:

1. **Decision** — what is being decided.
2. **Alternatives** — realistic alternatives considered.
3. **Recommendation** — the preferred option.
4. **Rationale** — why it fits the product, architecture and operational reality.
5. **Consequences** — what becomes easier, harder or constrained.
6. **Status** — Proposed, Approved, Superseded or Rejected.
