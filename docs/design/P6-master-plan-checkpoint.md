## Important implementation boundary

P6 closure does not mean the future implementation is already validated. During development, the project must still test exact design tokens, typography licensing/performance, responsive layouts, map rendering, accessibility, keyboard/focus, screen readers, device behaviour, motion, performance and real content/media.

These are implementation validation activities, not reasons to reopen completed design foundations without a controlled change.

## Content reality retained

All P6 decisions remain compatible with the initial content strategy:

- route creation;
- Google Street View where appropriate;
- own photography of viewpoints, landscapes and places;
- exterior monument documentation initially;
- future interior mapping through permissions and collaborations;
- future richer own 360° experiences.

The product is designed for the complete future experience without assuming all future content exists at launch.

3. confirm dependencies and required inputs;

5. only then begin the proposal → visual → approval → audit → GitHub workflow.
