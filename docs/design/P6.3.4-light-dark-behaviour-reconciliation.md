# P6.3.4 — Light / Dark Behaviour Reconciliation

**Status:** OPEN — NOT YET DESIGNED / AUDITED
**Reason:** The original P6.3 plan defines Light / Dark Behaviour as the fourth foundation. The current GitHub audit trail contains no canonical P6.3.4 record.

## Required scope

P6.3.4 must define how the approved Explore Luxembourg 360 visual language behaves across:

- light surfaces;
- dark surfaces;
- navigation and controls;
- maps and map overlays;
- place imagery and photography;
- system states;
- accessibility and contrast;
- user/system theme preference.

## Important constraint

This point must preserve the approved premium visual identity. Dark mode must not become a separate visual identity, nor should it simply invert every colour.

## Required process

Before P6.3.4 can be marked closed:

1. proposal and explanation;
2. visual demonstration;
3. explicit project approval;
4. audit;
5. final GitHub record.

## Relationship to other foundations

P6.3.4 depends on the approved P6.1 colour/visual language and must integrate with P6.3.1 iconography, P6.3.2 controls, P6.3.3 system states, P6.3.5 motion and P6.3.6 accessibility.
